## FAQ

### How do I open Clarvoyance?

Grab the hosted build via [Download Latest Build](https://larsl1998.github.io/clarvoyance-manifest-hub/), or serve the HTML project on your machine.

### Is a desktop install mandatory?

No. The web edition needs only a compatible browser.

### How are updates delivered?

Open the newest hosted build, or refresh your clone:

```bash
git pull
```

### Can I customize the experience?

Inspect the project sources for HTML, style, or script options. What you can change depends on the build you have.

### Local viewing fails. What next?

Make sure the server is started from the project root and that the browser points at the right port. A simple HTTP server often fixes problems that appear when files are opened as raw `file://` paths.
